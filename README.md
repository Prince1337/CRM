# Customer Relationship Management System

Ein vollständig entwickeltes CRM-System, das moderne Webtechnologien demonstriert und bewährte Praktiken in der Fullstack-Entwicklung zeigt.

## 🎯 Projektübersicht

Diese Anwendung ist ein vollständiges Customer Relationship Management System, das als Demonstrationsprojekt für fortgeschrittene Webentwicklungsfähigkeiten entwickelt wurde. Das Projekt zeigt die Implementierung einer professionellen Business-Anwendung mit modernen Technologien und Best Practices.

## 🛠️ Verwendete Technologien & Tools

### Backend-Entwicklung
- **Java 17** - Robuste Backend-Entwicklung mit objektorientierter Programmierung
- **Spring Boot** - Enterprise-Framework für RESTful APIs und Microservices
- **Spring Security** - Sichere Authentifizierung und Autorisierung
- **JWT (JSON Web Tokens)** - Token-basierte Authentifizierung
- **MySQL** - Relationale Datenbank für strukturierte Datenspeicherung

### Frontend-Entwicklung
- **TypeScript** - Typsichere JavaScript-Entwicklung
- **Angular 16** - Modernes Frontend-Framework mit Komponenten-Architektur
- **Bootstrap 5** - Responsive CSS-Framework für moderne UI/UX
- **RxJS** - Reaktive Programmierung für asynchrone Datenflüsse
- **Angular CLI** - Entwicklungstools und Build-Prozesse

### DevOps & Deployment
- **GitHub** - Versionskontrolle und Code-Management
- **Firebase Hosting** - Cloud-basiertes Frontend-Hosting
- **Hetzner Cloud** - Server-Hosting für Backend-Services
- **CI/CD** - Automatisierte Build- und Deployment-Prozesse

### Entwicklungstools
- **VS Code** - IDE für effiziente Entwicklung
- **Postman** - API-Testing und Dokumentation
- **MySQL Workbench** - Datenbank-Management
- **Chrome DevTools** - Frontend-Debugging
